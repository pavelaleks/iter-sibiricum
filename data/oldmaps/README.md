Привязка к местности (pipeline/oldmaps): равнопромежуточная коническая проекция + поворот и масштаб, подобранные по опорным точкам
(города, мысы). Лист 1914 г. — разворот из двух страниц с перекрытием около 100 px, поэтому каждая страница привязана отдельно
(model1914.json: L и R; средняя ошибка 10–14 px ≈ 20–30 км). Карта 1822 г. привязана одной моделью (ошибка около 16 px ≈ 80 км;
часть её — неточности самой карты). Тайлы: data/tiles/ethno1914.pmtiles (z1–5), data/tiles/weimar1822.pmtiles (z1–4).

Ареалы data/areas1914.geojson извлечены из карты 1914 г. по цвету заливки (эталоны — образцы легенды) и направлению штриховки
(якуты — «\», тунгусы — «/»), очищены морфологически и обрезаны по суше Natural Earth. Камчатка и Чукотка закрашены на карте
серыми палеоазиатскими заливками, неотличимыми по цвету от моря, поэтому их контуры построены по суше в границах, проведённых на
карте, — это самые грубые контуры. Буряты, алтайцы, тувинцы, кеты, камасинцы, айны, нанайцы на карте по цвету надёжно не
выделяются — для них остаются схематичные эллипсы. На карте 1822 г. народы подписаны, а не закрашены: она показывается только
подложкой.
