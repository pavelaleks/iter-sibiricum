# Iter Sibiricum

**Европейские травелоги о Сибири и её народах, 1800–1930.** Цифровой ресурс по итогам проекта Российского научного фонда о восприятии межнациональных отношений в Сибири.

*Iter* по-латыни — путь, путешествие, маршрут. Так учёные XVIII века называли и поездку, и её отчёт (*Iter Lapponicum* Линнея, 1732); название отсылает к этой традиции и к трём основам ресурса — маршрутам, текстам и встречам в пути.

**Сайт: https://iter-sibiricum.ru/**

Ресурс подготовлен при поддержке гранта Российского научного фонда № 25-28-20397, https://rscf.ru/project/25-28-20397/, и Правительства Республики Алтай.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `iter-sibiricum`) и загрузите в корень всё содержимое этой папки, включая `.nojekyll`.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка не нужна: всё — чистые HTML/JS/JSON, библиотеки (d3, 3d-force-graph) лежат в `assets/vendor`. Тексты — 72 МБ, в лимиты GitHub укладываются (файлы < 3 МБ).

## Публикации
Заполните `data/publications.json` по образцу `data/publications.example.json`.
`status`: `published` | `in_press` | `submitted`. Поля `groups` и `works` (id народов и книг) связывают публикацию с карточками на сайте. PDF можно положить в папку `pubs/`.

## Обновление данных
Все файлы в `data/` и `texts/` генерирует `analysis/10_build_site.py` из репозитория конвейера (`siberia-travelogues`). После изменения разметки: `bash run_all.sh`, затем скопировать `site/` сюда.

## Открытые выгрузки
- `data/export/iter-sibiricum-places.lpf.jsonld` — газеттир (640 мест, названных хотя бы в одном абзаце корпуса; проверка — `pipeline/validation/check_places.py`) в [Linked Places Format v1.1](https://github.com/LinkedPasts/linked-places-format) для [World Historical Gazetteer](https://whgazetteer.org): формы названий из книг со ссылками на абзацы, годы поездок, точность координат (`certainty`), ссылки на GeoNames и Wikidata.
- `data/export/iter-sibiricum-routes.geojson` — маршруты по поездкам (LineString) со статусом проверки и ссылками на абзацы.
- Обе выгрузки — часть атласа, лицензия CC BY-NC 4.0.
- `data/pages/{книга}.json` — соответствие абзацев страницам сканов Internet Archive.

## Английская версия
Переключатель RU / EN в шапке (или `?lang=en`). Перевод накладывается на страницу по словарю `assets/i18n-en.js` (`assets/i18n.js` — механизм: числа в ключах заменены на `#`, составные строки переводятся по частям); тексты книг не переводятся. Словарь собирается из `pipeline/i18n/`: `crawl.py` обходит сайт в английском режиме и записывает непереведённые строки, `sim.py` оставляет минимальный список, переводы добавляются в `t*.tsv`, `build.py` пересобирает словарь. Новые русские строки, которых нет в словаре, показываются по-русски.
