# Протокол разметки выборки описаний народов

Выборка: 250 фрагментов, в которых описан коренной народ Сибири. Выборка стратифицирована по стране автора и периоду поездки (`08_expert_sample.py`), веса страт учитываются в расчётах.

Предварительную разметку по этому протоколу выполнила языковая модель (поле `annotator = model`). Эксперт проверяет каждую единицу в рабочем месте (вкладка «Разметка»). Решения эксперта хранятся в `data/review/annotation_review.json` и заменяют предварительные метки при сборке (`09_expert_models.py`). В поле разметчика тогда записывается имя эксперта.

Размечается только фрагмент (абзац). Знания о книге в целом не учитываются.

## 1. Оценка (`pol`)

Как автор оценивает народ в этом фрагменте.

| Метка | Когда ставить |
| --- | --- |
| `pos` | Есть явная положительная характеристика народа или его черт: честность, гостеприимство, ум, мастерство, чистоплотность, «процветание и порядок». |
| `neg` | Есть явная отрицательная характеристика: грязь, леность, пьянство, «дикость», вороватость, «низшая ступень», уродство «по нашим понятиям». |
| `amb` | В одном фрагменте есть и положительная, и отрицательная оценка («честны во всём, кроме водки»). Сюда же сочувствие при отрицательной характеристике. |
| `neu` | Описание без оценочных слов: быт, одежда, хозяйство, численность, маршрут. |
| `invalid` | Фрагмент не описывает людей: топоним («Buriat steppe»), название книги, сноска, ошибка распознавания. Такие единицы исключаются из расчётов. |

Оценка относится к народу, а не к отдельному человеку. Исключение — когда человек явно подан как образец своего народа («typical Yakut»).

Если автор передаёт чужое мнение и не соглашается с ним (например, мнение торговца о «глупости туземцев»), ставится оценка самого автора. Если позиция автора не видна, ставится `neu`, а в комментарии пишется «чужая оценка».

## 2. Источник знания (`obs_m`)

| Метка | Когда ставить |
| --- | --- |
| `personal` | Автор описывает то, что видел сам в этой поездке: встречу, ночлег, разговор, сцену. |
| `reported` | Автор передаёт рассказ проводника, чиновника, миссионера, торговца. |
| `bookish` | Сведения взяты из книг: ссылка на Палласа, Гмелина, Кастрена и т. п., или пересказ чужого труда. |
| `generalization` | Общее суждение о народе без опоры на конкретную сцену («the Ostyaks are…»). |

Если в одном фрагменте есть и наблюдение, и обобщение, выбирается то, на чём держится оценка.

## 3. Рамка описания (`frame`)

Главная тема, в которой народ описан. Одна метка на фрагмент.

| Метка | Тема |
| --- | --- |
| `ethno` | Этнографическое описание: внешность, одежда, жилище, обычаи, язык. |
| `contact` | Бытовой контакт с автором или русскими: ночлег, ямщики, проводники, торговля на станции. |
| `econ` | Хозяйство и торговля: охота, оленеводство, ясак, долги, наём. |
| `relig` | Религия: шаманизм, крещение, миссия, ламаизм. |
| `conflict` | Конфликт и насилие: столкновения, побеги, наказания, войны. |
| `civ` | Иерархия «цивилизованности»: сравнение со ступенями культуры, «дикарями», колониями. |
| `decline` | Упадок, вымирание, болезни, водка. |
| `admin` | Власть и управление: инородческое управление, суды, сборщики. |
| `other` | Ничего из перечисленного. |

## 4. Проверка и согласие

Сначала эксперт проверяет все 250 единиц; это и есть экспертная разметка. Затем второй эксперт независимо размечает случайные 100 единиц, не видя чужих меток. По этим единицам считается α Криппендорфа для `pol` и `obs_m`. Если α ниже 0,67, спорные определения уточняются, и разметка повторяется.
