# Проверка маршрутов путешествий по тексту (Iter Sibiricum)

Задача: для каждой книги из своего списка восстановить маршрут путешествия автора по Сибири и прилегающим землям — только места, где автор (или его спутники вместе с ним) действительно был, в порядке поездки, с абзацем-доказательством для каждой остановки.

Материалы:
- Пакет книги: /home/claude/review/packets/<work_id>.md — метаданные, черновик программы (если есть) и все абзацы с упоминаниями мест.
- Полный текст: /home/claude/site/texts/<work_id>.json, поле "p": список [номер_абзаца, тип, регион, в_Сибири, текст, ...]. Читайте его, когда фрагментов в пакете мало (Read с offset/limit или python/grep по файлу).
- Справочник мест: /home/claude/review/places.csv (place_id, label_ru, координаты).

Правила:
1. Остановка = место, где автор был лично: прибыл, проехал, ночевал, жил. Не остановка: место, о котором автор только рассказывает, вспоминает, сравнивает, цитирует чужой рассказ, планирует; места поездок других людей.
2. Доказательство — номер абзаца, где из текста ясно, что автор там был. Цитата — не длиннее 25 слов, дословно из абзаца.
3. Порядок — по ходу поездки (а не по порядку упоминания). Если книга описывает несколько поездок, нумеруйте их (journey 1, 2…).
4. Места вне справочника можно добавлять: place_id = new:<латиница>, укажите название и приблизительные координаты, если уверены, иначе пусто.
5. Нельзя выдумывать: если не уверены, ставьте decision=unclear и объясните в note. Лучше меньше остановок, но все подтверждены.
6. Если книга не описывает поездку автора (обзор, компиляция, научный труд без маршрута) или текст непригоден — одна строка-заключение в books.csv, остановок не нужно.
7. Пропущенные европейские участки (Петербург, Москва) включайте, только если они в тексте как часть пути; карта показывает Сибирь, но маршрут должен быть цельным.

Выход — два файла в /home/claude/review/out/ с суффиксом вашей партии (например stops_b1.csv, books_b1.csv), UTF-8, с заголовком; дописывайте после каждой книги, чтобы работа не терялась:

stops_bN.csv: work_id,journey,seq,place_id,place_name,lat,lon,decision,evidence_pid,quote,note
  decision ∈ {visited, unclear}; evidence_pid — номер абзаца из пакета (5 цифр, как "00246"); seq — порядок в поездке.
books_bN.csv: work_id,has_journey,journeys,direction,years,stops,draft_precision_note,quality,summary
  has_journey ∈ {yes, no, unclear}; direction — откуда куда в 3–6 словах; quality ∈ {good, partial, poor_ocr, not_a_journey}; summary — 1–2 предложения по-русски: как проходила поездка; draft_precision_note — сколько остановок черновика подтвердилось и что программа ошибочно включила.

В конце верните короткий отчёт: сколько книг, сколько с маршрутом, типичные ошибки черновика.
